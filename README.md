Angry Birds — Python Edition
Простая реализация игры в стиле Angry Birds на Python с использованием библиотеки Pygame. Проект демонстрирует базовую 2D‑физику, обработку столкновений и игровой цикл.

🎮 Что это?
Игрок запускает птиц с рогатки, чтобы уничтожить всех свинок на уровне. Птицы обладают разными способностями, а блоки и свинки реагируют на попадания и падения.

⚙️ Как работает программа
1. Инициализация и настройки
pygame.init() — запуск библиотеки.

Константы: размеры окна (1000×650), гравитация (GRAVITY = 1200), сила выстрела (POWER = -7.5), максимальная натяжка рогатки (MAX_DRAG = 140).

Словарь SPRITES — зарезервированные пути к изображениям. Если спрайты не загружены, игра рисует всё примитивами (круги, прямоугольники).

2. Игровые объекты
Класс	Назначение
Bird	Птица. Хранит позицию, скорость, тип, способность. Метод update() применяет гравитацию, отскоки от земли/стен, защиту от застревания.
Pig	Свинка. Имеет HP, падает под действием гравитации, если под ней нет блока. Погибает при HP ≤ 0.
Block	Разрушаемый блок. При HP ≤ 0 «падает» и наносит урон другим блокам/свинкам при столкновении.
Game	Основной контроллер: меню, уровни, обработка событий, отрисовка, игровой цикл.
3. Типы птиц
Тип	Цвет	Урон	Способность
red	Красный	2	—
yellow	Жёлтый	2	Ускорение (speed) — увеличивает скорость полёта
black	Чёрный	3	Бомба (bomb) — взрыв по ЛКМ в полёте
4. Уровни
build_level(n) создаёт список свинок, блоков и очередь птиц.

Уровень 1: 2 свинки, 3 блока, 3 птицы.

Уровень 2: 4 свинки, 6 блоков, 5 птиц.

5. Игровой цикл
text
while True:
    dt = clock.tick(FPS) / 1000
    обработать события
    update(dt)     # физика, столкновения, проверка победы
    draw_*()       # отрисовка меню или игры
    flip()
6. Механика выстрела
Игрок тянет птицу мышью от рогатки — drag_pos ограничивается радиусом MAX_DRAG.

При отпускании вычисляется вектор (dx, dy) и птица получает скорость dx * POWER, dy * POWER.

Во время полёта рисуется траектория (55 точек с шагом 0.03 с).

7. Столкновения (check_collisions)
Птица ↔ свинка: если скорость > 150 и hit_cooldown ≤ 0 — свинка получает урон, птица замедляется.

Птица ↔ блок: при скорости > 250 блок получает урон (2 при скорости > 500), птица отскакивает с коэффициентом 0.4. Если после отскока скорость < 150 — птица останавливается.

Кулдауны (hit_cooldown) предотвращают многократное нанесение урона за один кадр.

8. Проверка победы/поражения
Победа: все свинки мертвы → экран победы, бонус +1000 за каждую оставшуюся птицу.

Поражение: птицы закончились, а свинки живы → экран «Птички закончились».

9. Управление
Действие	Клавиша/мышь
Выстрел	ЛКМ + перетаскивание
Способность	ЛКМ в полёте
Следующий уровень	Enter (на экране победы)
Рестарт	R
Меню	Esc

💡 Особенности реализации
Delta time (dt) — вся физика привязана к реальному времени, а не к кадрам.

Защита от застревания — если птица долго летит медленно (< 120), она останавливается.

Мягкое выталкивание — при касании свинки без достаточной скорости птица не отскакивает, а плавно смещается.

Падающие блоки — сломанный блок падает и может нанести урон другим объектам.
